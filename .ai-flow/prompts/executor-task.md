# Claude Code + DeepSeek 子任务执行提示词

你现在只执行当前 TASK 文件中的任务。

## 强约束

1. 必须先阅读 TASK 文件。
2. 只能修改 TASK 中“允许修改范围”内的文件。
3. 禁止修改 TASK 中“禁止修改范围”内的文件。
4. 不得修改 package.json 或 lock 文件，除非 TASK 明确允许。
5. 不得引入新依赖，除非 TASK 明确允许。
6. 不得做额外重构。
7. 不得顺手优化无关代码。
8. 不得改变现有业务语义，除非 TASK 明确要求。
9. 不得自动提交。
10. 不得自动推送。
11. 不得自动合并。

## 执行步骤

1. 阅读 TASK 文件。
2. 简要说明你对任务的理解。
3. 列出计划修改的文件。
4. 执行代码修改。
5. 检查是否修改了禁止范围内的文件。
6. 输出修改总结。
7. 输出风险点。
8. 输出建议验证命令。
9. 输出回滚建议。

## 完成后输出

请按以下格式输出：

一、修改文件清单

二、主要改动说明

三、风险点

四、建议验证命令

五、回滚建议
