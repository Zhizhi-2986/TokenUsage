# TASK-XX：任务名称

## 一、任务目标

说明本任务要完成什么。

## 二、任务背景

说明为什么要做这个任务，来源于哪个需求或问题。

## 三、允许修改范围

只允许修改以下文件或目录：

- 待填写

## 四、禁止修改范围

禁止修改以下文件或目录：

- package.json
- pnpm-lock.yaml
- yarn.lock
- package-lock.json
- .env
- .env.*
- 与本任务无关的业务模块
- 未在允许范围中列出的高风险文件

## 五、执行要求

- 不引入新依赖。
- 不做额外重构。
- 不顺手优化无关代码。
- 不改变现有业务语义。
- 不删除历史兼容逻辑。
- 改动必须可单独回滚。
- 不自动提交。
- 不自动推送。
- 不自动合并。

## 六、验收标准

- 功能符合任务目标。
- 原有核心流程不受影响。
- 没有修改禁止范围内的文件。
- 没有引入新依赖。
- lint 通过。
- typecheck 通过。
- test 通过。
- build 通过。

## 七、验证命令

根据项目实际情况填写，例如：

pnpm lint
pnpm typecheck
pnpm test
pnpm build

## 八、输出要求

完成后必须输出：

- 修改文件清单。
- 主要改动说明。
- 风险点。
- 验证结果。
- 回滚建议。
