# 高风险文件清单

以下文件或目录默认视为高风险。

AI 不得擅自修改，除非 TASK 文件明确允许。

## 一、依赖相关

- package.json
- pnpm-lock.yaml
- yarn.lock
- package-lock.json

## 二、环境配置

- .env
- .env.*
- config 中的环境配置文件
- 本地私有配置文件

## 三、构建与部署

- 构建配置文件
- 部署配置文件
- Dockerfile
- docker-compose.yml
- CI/CD 配置文件
- 发布脚本

## 四、框架核心

- 路由核心文件
- 权限控制文件
- 登录鉴权文件
- 全局状态管理文件
- 应用入口文件
- 框架适配层

## 五、公共能力

- 公共 API 客户端
- 公共请求封装
- 公共工具函数
- 公共组件库
- 全局样式
- 主题配置

## 六、修改高风险文件前必须说明

如果确实需要修改高风险文件，AI 必须先说明：

1. 为什么必须修改。
2. 修改会影响哪些模块。
3. 应该运行哪些验证命令。
4. 如何回滚。
